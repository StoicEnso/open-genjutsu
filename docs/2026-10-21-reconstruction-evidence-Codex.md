## Established interaction contract

- Separate source video and ordered appearance references.
- Motion-transfer and selected-object modes, with distinct validation and payload shapes.
- Prompt, resolution, scene mode, aspect ratio, batch and style controls.
- Source duration, reference count and scene-reference validation before submission.
- Duplicate submission protection and explicit quote/loading/error states.
- A synchronized original/result comparison.

The public full Genjutsu client permits different limits from this application. Those vendor limits are not capabilities of our local VACE/Wan implementation. Its credit quote depends on account/workspace and duration/resolution/batch, but no quote endpoint was invoked and no pricing rate was inferred.

## Independently implemented

We implemented our own local file handling, readiness checks, graph bindings, official Comfy SDK jobs, durable state, cancellation/recovery, comparison, immutable reruns and portable exports. The UI uses an original identity and original code. The repository contains no copied Higgsfield bundle, model, branding, demo clip, account data, or server implementation.

## Unknowns and limits

Client evidence does not establish Higgsfield's private model weights, internal rendering algorithm, complete server validation, output quality, runtime, exact billing implementation, or one-to-one feature parity. Open Genjutsu does not claim otherwise.

The local engine is a separately sourced Comfy workflow. Benchmark records distinguish real generation from model-free SDK/file-copy tests. A successful illustrative example does not establish human recasting, multi-person handling, long-clip continuity, or general identity fidelity.
