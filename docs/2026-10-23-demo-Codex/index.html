The actual local result

Wan VACE generated the inputs; LivePortrait animated Nova and Rowan from the same 49-frame performance. Each final cast took about 50 seconds on an M4 Pro with 24GB memory, producing 4.08 seconds at 12 fps.

Expressions, gaze and eyelids are approximate. This beta transfers portrait motion; body and scene replacement are outside this demonstration.

The separate Comfy Router BYOK mode is implemented and protocol-tested. Live paid generation and hosted output quality remain unverified.
